Cấu hình AI & API

Quản lý API Key, mô hình dịch AI và giọng đọc phát âm (Edge, Puter, Groq).

Danh sách API Key (Groq Cloud)

Tự động chuyển key tiếp theo khi gặp giới hạn Rate Limit 429 (Mỗi key 1 dòng hoặc cách nhau bởi dấu phẩy).

Chưa kết nối

Key được lưu cục bộ trên trình duyệt, không gửi đi nơi khác ngoài Groq.

Danh sách Puter Auth Token (Puter AI TTS)

Mở khóa các giọng đọc AI cao cấp: AWS Polly, OpenAI, Gemini 2.5, ElevenLabs, xAI Grok, Speechify.

Chưa kiểm tra

Token được lưu cục bộ trên trình duyệt, không gửi đi nơi khác ngoài Puter API.
